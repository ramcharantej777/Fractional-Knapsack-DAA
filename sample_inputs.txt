# Sample Inputs for Fractional Knapsack Project
# Format for programmatic input to main.c (stdin):
#   <capacity>
#   <number_of_items>
#   <name> <weight> <value>   (one per line, repeated n times)
#
# You can pipe a block into the compiled program, for example:
#   main.exe < sample_block.txt
# or copy one of the blocks below (without comment lines).
